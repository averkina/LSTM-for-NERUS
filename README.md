Провожу анализ качества аппроксимации выборки NERUS (предсказание POS
tag для токенов) моделью LSTM в зависимости от:
•
размера слоя;
•
числа слоев;
•
параметра dropout;
•
добавления BatchNorm;
•
размера словаря;

Все выводы представлены в формате tensorboard.
В данном задании демонстрируется умение работать с
моделью LSTM, а также умение преобразовать данные под разные модели и
данные.
